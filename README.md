# 🌐 Social Media Network Platform – Graduation Project

A modern and responsive **Social Media Network UI** built as part of my graduation project. The platform includes core user interface features such as **User Profiles**, **Posts**, and **Authentication (Login & Registration)**.

## 📌 Project Overview

This project focuses on designing the front-end UI for a social media network. The design aims to provide an engaging and intuitive experience, supporting basic user interactions and profile management. Though the primary focus is on the UI/UX, the project is structured to be extendable for full-stack development.

## ✨ Key Features

- 🔐 **Login & Registration UI**  
  Simple and responsive authentication pages for users to sign up and log in.

- 👤 **User Profile Interface**  
  Display profile information, profile picture, bio, and user-specific posts.

- 📝 **Post Feed UI**  
  View, like, and comment on posts in a scrollable feed layout.

- 📱 **Responsive Design**  
  Mobile-friendly layouts using modern front-end frameworks and clean CSS practices.

## 🛠️ Technologies Used

HTML5, CSS3, JavaScript, Bootstrap 5,  React.js
